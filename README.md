I build AI agents and automation end to end — from framing the business problem, through requirements, PoCs, and agent and workflow design, to the product UI. 事業課題の整理から、要件定義・PoC・AI エージェントと業務フロー設計・プロダクト UI まで一気通貫で作ります。既存ツールに AI を後付けするのではなく、AI ネイティブ前提で組みます。株式会社 Automate & Augment 代表 / 東京。

### Selected public work / 公開している仕事

- **[dwhy](https://github.com/Kazuya-Hibara/dwhy)** — A CLI that keeps decision records as the source of record, with seal-hash integrity and supersede chains. 意思決定を seal ハッシュと supersede チェーンで機械管理する決定記録 CLI。
- **[llm-wiki-bundle-design](https://github.com/Kazuya-Hibara/llm-wiki-bundle-design)** — A design for a Markdown knowledge base an LLM agent can navigate cheaply: schemas, retrieval doctrine, templates. LLM エージェントが安価に辿れる Markdown ナレッジベースの設計（schema・検索 doctrine・テンプレ）。
- **[roman-set](https://github.com/Kazuya-Hibara/roman-set)** — A JP content flow: topic and persona in, hook scripts, video prompts, and per-platform captions out. トピックとペルソナから台本・動画プロンプト・各 SNS キャプションを出す日本語コンテンツ flow。
- **[claude-code-agents-jp](https://github.com/Kazuya-Hibara/claude-code-agents-jp)** — 232 Japanese subagents for Claude Code, installable as a plugin. Claude Code 用の日本語サブエージェント 232 体を plugin として配布。
- **[manus-claude-orchestrator](https://github.com/Kazuya-Hibara/manus-claude-orchestrator)** — A skill that connects Manus Desktop and Claude Code, an early take on running work across agent harnesses. 2 つのエージェントハーネスを横断させる skill。
